# XssGuard

XssGuard is a beginner-friendly Flask project for learning web application security and understanding Cross-Site Scripting (XSS).

## Features

- **Flask routes:** Handles requests using different HTTP methods.
- **Form handling:** Accepts username input through a POST request.
- **Input validation:** Displays an error message when the username is empty.
- **Query parameters:** Reads search input from the URL.
- **Custom headers:** Adds a custom HTTP response header.
- **Cookies:** Sets a plain browser cookie.
- **Flask sessions:** Stores and retrieves session data.
- **DOM manipulation:** Updates a character counter in real time using JavaScript.
- **Jinja templates:** Displays submitted input with default HTML escaping.

## Technologies Used

- Python
- Flask
- HTML
- JavaScript
- Git and GitHub

## Setup and Run

1. Install Python 3.
2. Open a terminal in the project directory.
3. Install Flask:

   ```bash
   python -m pip install Flask
   ```

4. Start the application:

   ```bash
   python app.py
   ```

5. Open `http://127.0.0.1:5000` in a browser.

## Learning Goals

I am building this project incrementally to understand HTTP requests and responses, form handling, cookies, sessions, DOM manipulation, and XSS-related security concepts.

## Disclaimer

This project is intended for educational use and authorized security testing. It is not a production-ready security tool.
